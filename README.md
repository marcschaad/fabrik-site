# Fabrik Collective site

Static export of the Fabrik Site Studio draft. `index.html` is the whole site (styles, renderer and content inline).

- Edit content in the Studio, then export and replace `index.html`.
- Fonts: Adobe Fonts kit cib4apc ("Fabrik Collective · live site": marcschaad.github.io, fabrikcollective.com, www, localhost). The Studio keeps kit fet5zmc; swap it at export.
- Staging: this copy carries `noindex` and a blocking `robots.txt`. Remove both before pointing fabrikcollective.com here.
